# Leaf 1.3.0

Leaf is the new name for Scrawl. It now has the Sedge look shared by every webhookstudios app: one set of colors, fonts and icons, in light and dark mode.

- New icon.
- Menus and dialogs use the Sedge colors and fonts. Your notes keep their own colors and fonts.
- The package and command are now called `leaf` (it was `scrawl`). Installing it replaces the old package.
- Your notes from Scrawl are copied over the first time Leaf starts.
- Everything works exactly as before. Your settings and presets carry over.

Install:

```bash
sudo apt install ./leaf_1.3.0_all.deb
```
